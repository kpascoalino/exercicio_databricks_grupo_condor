# README
Este repositório foi criado para a prática, usando o Databricks Free Edition, de exploração de dados via SQL.
O script de criação das tabelas é de propriedade de Vinícius Fialho, apresentado em um workshop da Databricks.
A ideia é que a solução seja feita via SQL e não Pyspark, ou, outra linguagem.
Antes de iniciar a solução dos exercícios, rode o notebook 01, usando um cluster serverless, disponível no Free Edition.
